版本 1.0 · 2026-11-05 · 价格为当日核查值，活动价变化快，下单前以各平台结算页为准
机器可读版：同目录 `routing.yaml`（工作流直接 import） · 分镜打标签模板：同目录 `storyboard_template.csv`

## 怎么用（3 步）

1. 分镜表里每镜填两个标签：`shot_type`（镜头类型，6 选 1）+ `urgency`（high / low）
2. 按「阶段 × 镜头类型」查下面的路由表，得到模型和渠道，不再逐镜纠结选型
3. 草稿没锁定（seed / 构图 / 运动 / 台词时长）之前，禁止进正片层烧 API

## 全局护栏

- 一个模型一个主渠道：不在三个平台给同一个模型重复充值；促销渠道只做溢出
- 下单时长 = 镜头时长 + 2 秒（时长控制不精确，后期裁），成本估算也要按 +2 秒算
- 预算系数：正片按 1.5 倍返工预留；草稿按 3 倍抽卡设计（边际成本 ≈ 0，不设上限）
- Seedance 1080P 只批给 hero_cover 和 action_hard 的关键镜，其余一律 720P
- 一个项目期内冻结模型版本，防风格漂移；新项目开工前先用 1 个代表镜在候选模型间横评，胜者写进该项目的 preset override

## 成本速算

公式：正片成本 = Σ（每镜时长 + 2 秒）× 单价 × 1.5

60 秒对白短剧单遍示例（混排）：Wan3 720P 30 秒 ¥18.00 + Seedance 720P 15 秒 ¥22.65 + H3 768P 10 秒 ¥5.72 + 可灵 720P 有声 5 秒 ¥4.50 = **¥50.87**，带 1.5 倍返工约 **¥76**
对照：全走 Seedance 2.5 1080P 单遍 60 × 3.74 = **¥224.40**，还没算返工
