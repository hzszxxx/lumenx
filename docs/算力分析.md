
全云端算力组合：仙宫云是私有 GPU 云，Seedance、Wan 3 这些是厂商 API 云，LibTV 是聚合云。

合理化的核心原则：三层云，各干一件事

不要让三个云抢同一批镜头。按生产阶段分层，每层的计费方式正好对应该阶段的消耗特征：

第一层 · 草稿层（占生成量约 80%，要的是便宜地反复抽卡）

仙宫云（按小时计费，开机后边际成本≈0）：跑开源模型 Wan 2.2、H3 量化版。用途是试运动、试构图、找种子、批量出变体。这一层最大的价值不是画质，是返工不花钱 — 你的质检强度是抽 2–3 遍，草稿全压在这层，API 的钱一分不烧
LibTV 双11 的 0 积分额度：Wan3、Kling4、H3、Seedance 2.0 Fast&Mini 最长 30 天 0 积分，和仙宫云并行当第二条草稿队列。缺点是慢队列，所以只给不急的镜头

第二层 · 正片层（只跑定稿镜，按秒付费买最高画质）
草稿层锁死参数后，按镜头类型路由 — 这是整个方案的核心表：

一致性长镜头 / 多参考（猫主角团、微动漫人物团、15–30 秒一镜到底）→ Wan 3.0，阿里云百炼直调。它 20 个参考素材、30 秒长镜头就是为这个生的，720P ¥0.6/秒、1080P ¥1.2/秒。不急的同类镜头可以走 LibTV，那边 Wan3 现在 0 积分
复杂动作 / 易崩镜头（拟人动物直立行走、仪仗队、打斗、快速运镜）→ Seedance 2.5，火山方舟直调，720P ¥1.51/秒、1080P ¥3.74/秒。全片最贵的一档，所以只给高潮镜和封面镜。不急的可以走 LibTV 的活动价，720P 低至 ¥0.16/秒，但它进不了交付关键路径，队列不可控
人物情绪特写 / 电影感运镜→ 可灵 3.0，开放平台直调，720P 有声 ¥0.9/秒、1080P 有声 ¥1.2/秒。价格只有 Seedance 的三分之一，情绪戏性价比最高
对白音画一体（有台词、要口型和立体声一起出）→ H3 托管版，MiniMax 官方 API，768P $0.08/秒、2K $0.13/秒。这里要分清：仙宫云上的 H3 是草稿版 — 开源的只有 H3-Base，提示词系统 H3-Context-IR 和 2K 再生成都是 API 独占、自部署补不出来；定稿对白镜必须回到托管版，草稿版只验台词时长和走位
填充镜 / 空镜 / 转场→ Seedance 2.0 Fast&Mini 或 Wan 3.0 的 480P 档，哪边有活动走哪边。这类镜头不值得占任何旗舰模型的额度

第三层 · 后期层
超分和补帧放仙宫云（SeedVR2 跑在你按小时的卡上，不另付费）：草稿层出来的 768p 镜头如果质检意外通过，可以直接超分到 1080p 交付，省掉一次 API 重跑 — 这是仙宫云在正片层唯一的入场券，要靠质检把关，不能整片这么干。

账号也要合理化：只留 4 个付费入口
仙宫云 — 草稿 + 后期，固定成本
阿里云百炼 — Wan 3.0 正片主力，顺带 Qwen 图模型，图和视频一个账
火山方舟 — Seedance 2.5，只买关键镜
MiniMax 官方 — H3 托管定稿

LibTV 只开最便宜的年付档当活动通道，不进关键路径；可灵先走 LibTV 和聚合渠道跑量，月用量稳定超过约 200 秒再开直调账号；Veo 这类海外模型用 fal 按量偶发调用，不单独养账号。同一个模型在三个平台都充值，是这种组合最常见的浪费 — 规则定死：一个模型一个主渠道，促销渠道只做溢出。

这样分到底省多少 — 按 60 秒短剧单遍算
全走 Seedance 2.5 1080P：60 × 3.74 ≈ ¥224，带 2.5 倍返工约 ¥560
按上面的路由混排（30 秒 Wan3 720P + 15 秒 Seedance 720P + 10 秒 H3 + 5 秒可灵）：单遍约 ¥51，因为返工被草稿层吃掉，正片返工按 1.5 倍算约 ¥76
混排里再把不急的三分之一镜头挪去 LibTV 活动价：能压到 ¥40 上下，代价是交付时间不可控

差出近一个数量级，画质还更高 — 因为每一镜都用的是它最擅长的模型，而不是一个模型通吃。

落到你的项目类型，就是三个预设
萌宠/拟人动物：Wan 3 主力（约 60%）+ Seedance 补动作笑点（30%）+ H3 补音画（10%）
对白短剧/微动漫：H3 托管（40%）+ 可灵情绪戏（30%）+ Seedance 高潮（20%）+ Wan 3 长空镜（10%）
写实仪式类（升旗那种）：Seedance 主力（70%）+ Wan 3 长镜头（30%），不用 H3 和可灵
